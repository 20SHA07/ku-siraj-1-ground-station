      Data contract: one JSON object per message (MQTT payload or USB serial line)

      {"device_id":"ku-siraj-1","packet_id":12,
 "timestamp":"2026-11-09T08:00:00Z",
 "operating_mode":"SUNLIGHT",
 "solar_voltage_v":4.9,"solar_current_ma":55.2,
 "battery_voltage_v":3.84,"temperature_c":26.1,
 "predicted_op_min":72,"safe_window":2,
 "motion":1,"event_count":42,
 "light_lux":620,"pitch_deg":1.3,"roll_deg":-0.8,
 "lora_rssi_dbm":-85,"simulated":false}

device_id, packet_id required. timestamp: ISO 8601 UTC,
set by the publisher on receipt if the ESP32 has no clock.
Channel not wired  -> leave the field out.
Sensor read failed -> send the field as null.
Primary (predictor): predicted_op_min (minutes of safe
operating time remaining, ML regression output),
safe_window (2=safe, 1=caution, 0=unsafe).
Primary (presence): motion (1=detect, 0=clear),
event_count, pitch_deg, roll_deg (MPU-6050 heading
for 360° presence mapping), light_lux (LDR).
Secondary: pem_voltage_v, pem_current_ma.
Optional: battery_current_ma (+ = discharging),
load_voltage_v, load_current_ma, *_power_mw,
packet_success_pct, orbit_phase_deg (0 = shadow centre).
Power is V × mA when *_power_mw is omitted.
      KU-SIRAJ 1 · Team KU-SHIHAB · SatForge UAE 2026. Read-only ground station for the KU-SIRAJ 1 autonomous operations predictor. Primary mission: onboard ML model predicts remaining operating time and classifies safe/caution/unsafe operating windows from power, thermal and illumination telemetry; 360° presence-mapping demo combines MPU-6050 gyro heading with HC-SR501 PIR detections to build a polar occupancy map. Secondary mission: PEM hydrogen fuel cell power experiment (~45 mW, ~14% of load). This is a bench/ground demonstration, not flight hardware. PEM figures are provisional until bench-verified. Simulated and replayed values are labelled and are not measurements. The demo uses the team's Multisim 14.1 power-path model with simulated PIR triggers and synthetic prediction outputs. Live data travels over a public MQTT test broker; the page validates every packet. Limits are provisional: predicted op time warn 15 min / critical 5 min, battery warn 3.5 V / critical 3.3 V, temperature warn 40 °C / critical 45 °C, RSSI warn −105 / critical −115 dBm, packet success warn 95 % / critical 80 %, stale after 5 s. Times are Gulf Standard Time (UTC+4). Setup, data contract and test plan: github.com/20SHA07/ku-siraj-1-ground-station.
